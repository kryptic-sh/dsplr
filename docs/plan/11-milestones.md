# 11 — Milestones

Build order. Each milestone ends green (`cargo fmt --all`,
`cargo clippy --workspace --all-targets -- -D warnings`,
`cargo test --workspace`) with its tests in place, and is committed and pushed
before the next one starts. A milestone's plan sections are trimmed to what is
still open once it lands.

| #   | Milestone                          | Delivers                                                                                                                                                                                                                  | Exit check                                                                                                                                                                                                                             |
| --- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M0  | Scaffold (done)                    | Workspace with every crate stubbed honestly, CI, repo meta, this plan                                                                                                                                                     | CI green                                                                                                                                                                                                                               |
| M1  | Model + Hyprland read + CLI (done) | `dsplr-model`, Hyprland `snapshot`, `dsplr list [--json]`, `dsplr backend`. The change stream comes from `wlr-output-management` events, so it moves to M2 with `crcbl-wayland`                                           | Model unit tests; Hyprland translation tests on recorded replies; `dsplr list` matches `hyprctl monitors all` on the owner's machine                                                                                                   |

M0–M7 is the MVP: the owner's Hyprland replacement first (M3), then every other
desktop in scope. M8 is post-MVP. M9 is cut when the owner says the MVP is good
enough, and needs every crcbl crate dsplr uses released on crates.io.
